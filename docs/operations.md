## 管理画面へのアクセス

### スマートフォンからのアクセス

1. ブラウザ（Safari/Chrome）で以下のURLを開く
   ```
   https://<your-domain>/admin/login
   ```
   例: `https://my-line-bot.vercel.app/admin`

2. **ログインパスワード**を入力して「ログイン」を選択
   - パスワードは開業時に開発者から共有されます
   - 忘れた場合は開発者に連絡してください

3. ログイン成功後、ホーム画面が表示されます

### ホーム画面

ホーム画面には以下4つのメニューが表示されます。

| メニュー | 説明 |
|---------|------|
| **FAQ管理** | よくある質問と答えを管理 |
| **メニュー・料金** | 施術メニューを表示・管理（Bot未連携） |
| **会話ログ** | 顧客からのメッセージと Bot の応答を確認 |
| **お知らせ配信** | 全顧客へのお知らせを一斉配信 |

### セッション（ログイン状態）

- ログイン状態は **30日間有効** です
- 30日経つと自動的にログアウトされます
- ブラウザタブを閉じてもログイン状態は保持されます（別のタブで開き直しても OK）

## 画面ごとの使い方

### FAQ管理（`/admin/faq`）

**Bot がこの内容を使って顧客からの質問に答えます。**

#### よくある質問を追加

1. 「新しいFAQを追加」を選択
2. 以下を入力
   - **質問**: 顧客が聞きそうな内容（最大200字）
   - **答え**: Bot が返信する内容（最大1000字）
   - **カテゴリ**: 任意（例: 営業時間、料金など）
   - **公開**: チェックを入れる（Bot が回答に使用）
3. 「保存」を選択

#### よくある質問を編集

1. FAQ一覧から質問を選択
2. 内容を修正
3. 「保存」を選択
   - **変更は即座に Bot の回答に反映されます**

#### よくある質問を削除

1. 質問を選択
2. 「削除」を選択
3. 確認ダイアログで「はい」を選択

#### 表示順序を変更

1. FAQ一覧で質問をドラッグ&ドロップで並び替え
2. 自動保存されます

**注意**: 複数の FAQ を同時に順序変更する場合、部分的に失敗することがあります。その場合は開発者に連絡してください。

### メニュー・料金（`/admin/menus`）

**ここで登録した内容は、現在 Bot の自動応答には反映されません。**

操作方法は FAQ 管理と同様です。
- **メニュー名**: 施術の名前（最大100字）
- **説明**: 詳細（最大500字）
- **価格**: 円単位（0円以上）
- **所要時間**: 分単位（1分以上）

### 会話ログ（`/admin/conversations`）

**顧客からのメッセージと Bot の応答を確認できます（読み取り専用）。**

#### ログの見方

| 情報 | 説明 |
|------|------|
| **顧客ID** | 顧客の LINE ID（プライバシー保護のため末尾4字のみ表示） |
| **方向** | 顧客がメッセージを送信 / Bot が返信 |
| **メッセージ** | 実際のテキスト内容 |
| **回答の確かさ** | Bot の回答の確かさ（高い／ふつう／低い）。判定していない返信には表示されません |
| **スタッフ確認あり** | Bot が自動で回答せず、オーナー（管理者）の LINE へ通知したやり取り |

#### ログの検索・フィルタ

- 画面上部の「スタッフ確認あり」を選ぶと、スタッフの確認が必要になったやり取りがあるお客様だけを表示します
- 新しいメッセージが上に表示されます

#### 削除

管理画面からログを削除することはできません。ログは自動では削除されず、保存され続けます（お客様の LINE ユーザーID を含む個人情報のため、取り扱いに注意してください）。

## お知らせ安全配信ガイド

**このセクションは最も重要です。必ず手順を守ってください。**

### お知らせ配信の全体フロー

```
1. 下書き作成
   ↓
2. テスト送信（オプション）← オーナーのLINEにのみ送信。本配信状態に影響なし。
   ↓
3. 本配信（確認後、友だち全員へ一斉配信）
   ↓
4. 配信完了
```

### ステップバイステップ

#### 1. 下書き作成

1. お知らせ配信画面（`/admin/announcements`）を開く
2. 本文を入力（最大1000字）
   - 空白のみ（スペース・改行のみ）は不可
   - 制御文字（見えない文字）は使用不可
3. 「保存して次へ」を選択
   - 下書き状態で保存されます

#### 2. テスト送信（推奨）

本配信する前に、必ずテストしてください。テスト送信はあなたのLINEにのみ配信されます。

1. 下書き一覧から当該お知らせを選択
2. 「自分にテスト送信」を選択
3. 確認画面で内容を確認して「テスト送信」を選択
4. LINEを確認
   - あなたのLINEに同じ内容が配信されます
   - **この段階では友だち全員には送信されていません**
   - 画面上の状態は「下書き」のままです（OK）

#### 3. 本配信（友だち全員へ）

テスト内容が問題ないことを確認したら、本配信します。

**⚠️ 重要: この操作は取り消せません。友だち全員のLINEに届きます。**

1. 下書き一覧から当該お知らせを選択
2. 「友だち全員へ配信」を選択
3. **確認ダイアログをよく読む**（本当に配信してよいか確認）
4. ダイアログで「配信する」を選択
5. 配信開始
   - ステータスが「配信処理中」に変わります
   - 配信が完了するまで数秒～数分待ちます

#### 4. 配信完了確認

- ステータスが「配信済み」に変わったら成功です
- LINE Official Account Manager でも配信ログを確認できます

### ステータスの意味

| ステータス | 説明 | 次のアクション |
|-----------|------|---|
| **下書き** | まだ友だち全員には送信されていない | テスト送信 / 本配信 / 削除 |
| **配信処理中** | LINE へ送信中。数分以内に完了予定 | 待機（再送・中止不可） |
| **配信済み** | LINE が受け付けた。友だち全員に配信済み | なし（完了） |
| **配信失敗** | エラーが発生した | 原因を確認して再送（24時間以内） |
| **状態確認が必要** | 処理が長時間停止している | LINE Official Account Manager で状況確認 |

### 重要な注意事項

#### 本文について

- **最大1000字**（スペースを含む）
- 改行・タブは OK、制御文字（見えない文字）は NG
- 前後の空白を含めて配信されます（trimされません）

#### 配信数の確認

配信前に **LINE Official Account Manager** で月間配信残数を確認してください。

1. [LINE Official Account Manager](https://manager.line.biz/) にログイン
2. 「メッセージ」 → 「配信」 → 「配信数」を確認
3. 配信対象の友だち数 × 1 = その配信で消費するメッセージ数

例: 100人の友だちがいる場合、1回の配信で100メッセージを消費します。

#### 二重配信について

以下の場合、二重配信を防止する仕組みが働きます。

**ネットワーク不調で「配信処理中」のまま停止した場合:**
- LINE側では既に友だち全員に配信されている可能性があります
- 再送する前に、LINE Official Account Manager で実際に配信されたか確認してください
- 配信されていれば、再送しないでください
- 詳細は [「状態確認が必要」対応](#状態確認が必要対応) を参照

## トラブルシューティング

### 「配信処理中」のまま進まない

配信処理が10分以上完了しない場合、画面に「**状態確認が必要**」という警告が表示されます。

#### 対応手順

**ステップ1: LINE Official Account Manager で確認**

1. [LINE Official Account Manager](https://manager.line.biz/) にログイン
2. 「メッセージ」 → 「配信」 → 配信ログを開く
3. 当該お知らせの送信日時を確認
4. 配信済みか失敗か確認

**ステップ2: 管理画面で状態を修正**

配信されていた場合、配信済みに修正します（開発者に依頼）。
配信されていなかった場合、配信失敗に修正します（開発者に依頼）。

開発者へ以下を伝えてください：
- 配信履歴に表示されている作成日時と本文の冒頭（お知らせのIDは画面に表示されません）
- LINE Official Account Manager で配信されたかどうか
- 希望する状態（配信済み / 配信失敗）

開発者は SQL Editor で、まず対象のお知らせのIDを確認します：

```sql
select id, created_at, sending_started_at, left(body, 30) as body_head
from public.announcements
where status = 'sending'
order by created_at desc;
```

確認したIDを使って、以下のどちらかを実行します：

**配信されていた場合（配信済みに修正）:**
```sql
update public.announcements 
set status = 'sent', sent_at = now(), error_message = null 
where id = '<お知らせのID>' and status = 'sending';
```

**配信されていなかった場合（配信失敗に修正）:**
```sql
update public.announcements 
set status = 'failed', error_message = '手動で失敗に戻しました（配信されていないことを確認済み）' 
where id = '<お知らせのID>' and status = 'sending';
```

### 配信に失敗した

ステータスが「**配信失敗**」と表示された場合：

1. エラーメッセージを確認
2. 24時間以内なら「再送」ボタンで再配信可能
3. 24時間後は、内容を確認して新しいお知らせとして作成してください

### ログインできない

- パスワードが間違っていないか確認
- ブラウザのキャッシュをクリアして再度試す
- 別のブラウザで試す
- 何度も間違えた場合、WAF（ファイアウォール）でブロックされている可能性があります。1時間待ってから再度試してください。
- 解決しない場合は開発者に連絡

### メッセージが返信されない

- LINE Bot が友だち追加されているか確認
- テキストメッセージのみ対応しています（画像・スタンプには固定の案内文を返信します）
- Bot が FAQ から回答できない場合、お客様には「スタッフが確認します」旨を返信し、オーナー（管理者）の LINE へ通知が送られます

### 古いメッセージ内容が表示されている

FAQ を編集した場合、新しい内容で回答するようになります。
ブラウザキャッシュの場合もあるため、キャッシュをクリアして再度読み込んでください。

## セキュリティ設定

### パスワード変更

管理画面内にパスワード変更機能はありません。変更が必要な場合は開発者に連絡してください。

**注意**: パスワード変更では、既存のログイン状態（Cookie）は無効にはなりません。
ログイン中のセッションを一斉に無効にするには、秘密キー（ADMIN_SESSION_SECRET）をローテーションする必要があります。

### 全員をログアウトさせる

セッション秘密キーをローテーションすると、全員のログイン状態が無効になります。

**ローテーション手順:**

1. 開発者が Vercel > Project > Settings > Environment Variables で `ADMIN_SESSION_SECRET` を新しい値に変更
2. Vercel へ再デプロイ
3. 全員が再ログインが必要になります（事前アナウンス推奨）

### パスワード長

- 最小: 12字
- 推奨: 16字以上のランダム文字列
- パスワードは絶対に共有しないでください

## テストデータに関する注意事項

### 背景

開発・テスト時に、以下のテストデータが本番 Supabase に作成されている可能性があります：

- テスト FAQ（実際に使われない質問）
- テスト会話ログ（テスト LINE アカウントからのメッセージ）
- テスト下書き（配信予定がないお知らせ）
- テスト配信済み（テスト配信で消費したメッセージ数）

### クリーンアップ

本番運用開始前に、必ず以下を確認・削除してください。

#### テスト FAQ の確認・削除

1. 管理画面 > FAQ管理 を開く
2. 以下のような質問を探して削除
   - 「テスト」「test」を含む
   - 実際の営業に不要な内容

または開発者に以下を実行してもらう（SQL Editor）：
```sql
select id, question, created_at from public.faq 
where question like '%テスト%' or question like '%test%';
```

#### テスト下書きの確認・削除

1. 管理画面 > お知らせ配信 を開く
2. 「下書き」ステータスで、実際に配信しないものを削除

または開発者に以下を実行してもらう（SQL Editor）：
```sql
select id, body, created_at, status from public.announcements 
where status = 'draft' and created_at < now() - interval '7 days' limit 20;
```

下書きの削除：
```sql
delete from public.announcements 
where id = '<ID>' and status = 'draft';
```

### 会話ログ（削除不可）

会話ログには顧客の LINE ユーザーID（個人データ）が含まれます。管理画面では末尾4字のみ表示されていますが、実際のデータは安全に保管されています。

- 削除はできません（運用上の必要性のため）
- エクスポート・共有は絶対にしないでください
- 必要に応じて開発者に削除をリクエストできます

### 自動テスト

ユニットテストはテスト用に LINE API と Supabase をモック化しており、実際のテスト送信や配信は行いません。本番データに影響はありません。

## よくある質問

### Q: FAQ を編集したら、すぐに Bot が新しい回答を使いますか？

A: はい。FAQ を保存してから数秒で反映されます。ブラウザをリロードする必要はありません。

### Q: 顧客からのメッセージに Bot が応答しない場合は？

A: 以下の原因が考えられます：
1. 該当する FAQ がない → オーナー（管理者）の LINE へ通知が送られます
2. テキスト以外のメッセージ（画像・スタンプ） → エラーメッセージが返信されます
3. LINE Bot が友だち追加されていない → 友だち追加してください
4. ネットワークエラー → 時間を空けて再度試してください

### Q: 月間配信上限に達したら？

A: 新しい月を待つか、LINE プラン をアップグレードしてください。

### Q: お知らせを削除できますか？

A: 下書き状態なら削除できます。配信済み / 配信失敗 / 配信処理中は削除不可（ログとして保持）。

### Q: 同じお知らせを2度配信したい場合は？

A: 配信済みのお知らせは複製できません。同じ内容で新しく下書きを作成してください。
